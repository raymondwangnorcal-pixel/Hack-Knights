# Sample clips

Played by the **Sample** button on the listening screen: Lagos uses `anopheles-gambiae.wav`, São Paulo uses `aedes-aegypti.wav`. The clip plays out loud, draws on the spectrogram and is sent to `/api/classify`.

**These two files are synthetic placeholders** (a generated wingbeat tone with harmonics, not real recordings). Replace them with real Abuzz clips before the demo: same filenames, WAV, mono, 5–10 s. Any sample rate works.
